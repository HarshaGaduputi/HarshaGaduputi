## Selected work

### [SimplLife](https://github.com/HarshaGaduputi/SimplLife) · Full-stack task management

A React and TypeScript application for managing group-based workflows, tasks, subtasks, templates, priorities, due dates, and activity history.

- Built a Node.js/Express API with PostgreSQL persistence, JWT authentication, validation, rate limiting, and security middleware
- Added AI-assisted subtask generation with a rule-based fallback, plus 50-step undo/redo and soft-delete recovery
- Designed responsive light/dark interfaces with Zustand state management, search, calendar views, and import/export

`React` `TypeScript` `Node.js` `Express` `PostgreSQL` `Zustand` `Tailwind CSS`

### [Urban Energy Efficiency Analysis](https://github.com/HarshaGaduputi/Machine-Learning-Case-Study) · Collaborative ML case study

An end-to-end study of **75,757 buildings and 64 features**, covering data quality, feature engineering, regression, classification, cross-validation, and hyperparameter tuning.

- Compared 10 regression algorithms; Random Forest reached **0.5029 test R²** and **0.5566 ± 0.0105 cross-validated R²**
- Compared 5 classifiers; KNN reached **76.45% accuracy**, while Decision Tree achieved **0.8501 ROC-AUC**
- Documented preprocessing choices, leakage prevention, limitations, and failed-model analysis—not just the winning result

`Python` `pandas` `NumPy` `scikit-learn` `Jupyter` `Matplotlib` `Seaborn`

### [Website AI Agent](https://github.com/HarshaGaduputi/Team_Finishers_E101A) · Semantic retrieval and navigation

A Python prototype that crawls website content, builds a searchable vector index, and maps natural-language requests to relevant pages.

- Generates sentence embeddings with `all-MiniLM-L6-v2` and stores them in ChromaDB
- Ranks indexed pages with cosine similarity and uses a confidence threshold before navigation
- Connects retrieval to browser automation through Playwright

`Python` `Sentence Transformers` `ChromaDB` `BeautifulSoup` `Playwright`

### [NLP Lab](https://github.com/HarshaGaduputi/NLP) · Language-processing experiments

A collection of NLP coursework and utilities spanning n-gram language modelling and PDF-to-glossary translation workflows with structured JSON and Markdown outputs.

`Python` `NLP` `N-grams` `PDF parsing` `Translation workflows`
