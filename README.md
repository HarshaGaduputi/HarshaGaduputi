## About

I am a third-year Computer Science and Engineering undergraduate focused on building complete, usable systems — from interfaces and APIs to data pipelines, machine-learning workflows and intelligent retrieval.

My repositories currently span four main areas:

- **Full-stack engineering** — React, TypeScript, Node.js, Express, PostgreSQL, authentication, APIs and production-oriented tooling.
- **Applied machine learning** — end-to-end EDA, preprocessing, feature engineering, regression, classification, model evaluation and hyperparameter tuning.
- **NLP and intelligent retrieval** — n-grams, multilingual text workflows, sentence embeddings, semantic search and browser-assisted agents.
- **Algorithms and systems** — Java algorithm design plus low-level operating-systems coursework using eXpOS, SPL and XSM.
